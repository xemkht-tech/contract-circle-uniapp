# 契圈（原型）

基于 `uni-app + Vue 3 + TypeScript` 的微信小程序跨端骨架。

## 当前实现

- 兴趣社区、交易市场、个人中心三个一级页面
- 依照信用分区间的前端权限展示（50 / 60 / 75 / 95 / 100 分）
- 可解释的信用记录与邀请担保说明
- 页面未直接访问数据库；后续可由统一 API 对接微信云开发或自有后端

## 本地启动

当前环境未安装 Node.js。安装 LTS Node.js 后，在本目录执行：

```bash
npm install
npm run dev:mp-weixin
```

然后用微信开发者工具导入生成的 `dist/dev/mp-weixin`。发布 H5 可执行 `npm run dev:h5`。
